# AI POLICY

We support using AI as tools for coding. However, we require a human
to be responsible for any contributions to our repositories.

Only humans may:
- Open issues and pull requests.
- Author un-quoted text in pull requests, issues and comments.

In the following "you" refers to the human opening the issue or pull request.

### Expectations when opening an issue or PR

When opening an issue or pull requests, we require that you

- Are able to explain the issue or change in your own words.
- That you have reviewed any AI-generated code and can explain it in your own words.

### Use quote blocks for AI-generated text

If you wish to include context from an interaction with AI in your 
comments, it must be in a quote block (e.g., using `>`) and disclosed as such. 
It must be accompanied by commentary where you explain the relevance and implications 
of the context.
