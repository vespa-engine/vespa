# Vespa clients

Standalone Vespa clients and client-side libraries:

   - [`go/`](go/README.md): The Vespa CLI.
   - [`src/`](src/README.md): The Vespa Query DSL: Library for creating YQL queries in Java.
   - [`js/`](js/README.md): Query builder and trace vislaizer (experimental).

See also [pyvespa](https://pyvespa.readthedocs.io/en/latest/), the Vespa Python client.
